## Stream fields

Market-data masks OR `1 << fieldId` using the dataset's Universe field ID (0..63), without subtracting one. Listing subscriptions send the same field IDs. A zero market-data mask selects all supported fields. Batch rows carry the field ID; each request first receives a DatasetFields response naming the semantic field and the payload layout (its SBE message name) of every ID it uses. Select the decoder by these names; each row carries the payload's version and block length.

| Semantic field | Universe field ID | Public mask (hex) | Owner schema | Message | Commands |
| --- | ---: | --- | --- | --- | --- |
